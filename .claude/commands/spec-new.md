## Instructions

1. Ask the user: "What feature are you speccing? Describe it in 1-2 sentences."
2. Determine the next available spec number by looking at existing files in `specs/`.
3. Copy the structure from `specs/00-template.md`.
4. Fill in what you can based on the user's description — leave blanks where you need more information.
5. Set Status to `draft`.
6. List any Open Questions that must be resolved before implementation can start.
7. Save the file as `specs/NN-short-name.md`.
8. Show the user the spec and explain each section in plain language.
9. Ask: "Does this look right? What should we change or add?"

## Rules

- Do not start implementation — this command is spec-writing only.
- Flag any ambiguity as an Open Question rather than making assumptions.
- Keep the Goal to one sentence.
- Out of Scope must have at least one entry.
